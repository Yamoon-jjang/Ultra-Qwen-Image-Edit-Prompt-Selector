# v4.0.0 — Korean / English bilingual release

## 한국어

**Ultra Qwen Image Edit Prompt Selector v4**의 한·영 공용 첫 공개 릴리스입니다.

- **4,927개 프리셋**을 1~3장 이미지 편집 모드별로 제공
- Qwen-Image-Edit-2511과 Qwen-Image-2.1 이미지 편집용 영어 프롬프트 작성 지원
- **KO/EN UI 전환:** 한국어 모드에서는 영문 지시와 한글 설명을 함께, 영어 모드에서는 영문만 표시
- 프리셋 검색·조합, 충돌 표시, 참조 이미지 역할 지정, 커스텀 프리셋 관리
- 프롬프트 복사·TXT 저장, 브라우저 저장 및 HTML 파일에 영구 저장
- **한글·영문 상세 메뉴얼** 및 언어별 README 스크린샷 제공

**설치 방법:** 첨부 ZIP을 풀고 `Ultra_qwen_prompt_selecter_v4.html` 파일을 Chrome 또는 Edge로 여세요. 서버·설치 프로그램·ComfyUI 실행은 필요하지 않습니다. 실제 이미지 편집은 별도의 Qwen 실행 환경이 필요합니다.

## English

Initial bilingual public release of **Ultra Qwen Image Edit Prompt Selector v4**, a standalone browser-based prompt-writing tool.

- **4,927 built-in image-editing presets**, organized for 1, 2 or 3 input images
- Designed for **Qwen-Image-Edit-2511** and **Qwen-Image-2.1** image-editing workflows
- **Korean / English interface switch**, with Korean annotations hidden in EN mode
- Preset browsing and bilingual search, conflict handling and explicit `image1`–`image3` roles
- Editable saved custom presets, copy/TXT export and permanent HTML save option
- Extensive **Korean and English manuals** and language-appropriate README screenshots

**Get started:** Download and extract the attached ZIP, then open `Ultra_qwen_prompt_selecter_v4.html` in Chrome or Edge. No installation or ComfyUI runtime is required for prompt writing. An external compatible Qwen workflow is required to generate edited images.

> This release is a prompt builder, not an image generator or a ComfyUI custom node.
