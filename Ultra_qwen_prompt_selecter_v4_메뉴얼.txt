Ultra Qwen Image Edit Prompt Selector v4 공개 사용자 메뉴얼
파일명: Ultra_qwen_prompt_selecter_v4_메뉴얼.txt
대상 앱: Ultra_qwen_prompt_selecter_v4.html
용도: Qwen-Image-Edit-2511 및 Qwen-Image-2.1용 이미지 편집 프롬프트 생성

============================================================

이 문서는 Ultra Qwen Image Edit Prompt Selector v4 공개 배포본을 처음 사용하는 사람도 실제 이미지 편집 작업까지 따라 할 수 있도록 정리한 상세 사용자 메뉴얼입니다.
개발 과정이나 내부 수정 이력보다, 어떤 이미지를 어떤 순서로 넣고 어떤 프리셋을 선택해야 하는지에 초점을 맞춥니다.
앱은 Qwen-Image-Edit-2511 또는 Qwen-Image-2.1의 이미지 편집 워크플로우에 넣을 영어 직접 명령형 프롬프트를 빠르게 만들기 위한 단일 HTML 도구입니다.


지원 모델 안내 (2511 / 2.1):
- Qwen-Image-Edit-2511: 이미지 편집 전용 모델용 프롬프트로 사용합니다.
- Qwen-Image-2.1: 이미지 생성과 편집을 모두 지원하는 통합 모델입니다. 이 앱은 그중 입력 이미지를 사용하는 편집 작업의 지시문을 만듭니다.
- 이 앱은 모델 실행기나 모델 전환기가 아닙니다. 사용하는 ComfyUI 등 워크플로우에서 모델과 이미지 입력을 별도로 지정해야 합니다.
- Qwen-Image-2.1 모델 자체는 더 많은 참조 이미지를 처리할 수 있지만, 현재 앱의 이미지 역할과 프리셋은 1~3장까지만 지원합니다.
- 기존 Qwen-Image-Edit-2509 계열에서도 워크플로우가 호환된다면 생성 문구를 참고할 수 있습니다. 다만 모든 모델에서 동일한 편집 결과를 보장하지는 않습니다.
- 모델에 따라 프롬프트 해석·참조 이미지 처리·유지 성능이 다를 수 있으니 실제 출력 이미지로 결과를 확인하십시오.

1. 앱 개요
------------------------------------------------------------

Ultra Qwen Image Edit Prompt Selector v4는 이미지 편집용 프롬프트를 버튼 선택 방식으로 조합하는 앱입니다.
사용자는 이미지 개수(1개 / 2개 / 3개)를 먼저 고르고, 얼굴·의상·포즈·배경·조명·스타일·소품·디테일 같은 편집 항목을 선택합니다.
그러면 앱은 선택 내용을 Qwen Image Edit가 이해하기 쉬운 영어 명령문으로 정리합니다.

v4의 핵심 사용 방향은 다음과 같습니다.

- Base / Reference 같은 역할 드롭다운을 제거했습니다.
- 모든 안내를 image1 / image2 / image3 기준으로 통일했습니다.
- image1은 편집할 원본 이미지입니다.
- image2는 첫 번째 참조 이미지입니다.
- image3은 두 번째 참조 이미지입니다.
- 프리셋 한글 문구를 더 쉬운 표현으로 정리했습니다.
- 1장 / 2장 / 3장 프리셋을 서로 분리했습니다.
- NSFW 항목은 별도 cat:'nsfw'가 아니라 일반 카테고리 아래 nsfw:true 속성으로 관리합니다.
- 커스텀 항목 저장과 영구 저장 기능을 지원합니다.
- 일반 항목과 NSFW 항목 모두 실제 편집 대상, 참조 이미지 역할, 유지 조건을 사용자가 쉽게 알 수 있도록 정리했습니다.

------------------------------------------------------------

ZIP 파일 안에는 보통 다음 파일이 들어 있습니다.

- Ultra_qwen_prompt_selecter_v4_메뉴얼.txt
  지금 보고 있는 공개 배포용 사용 설명서입니다.

- Ultra_qwen_prompt_selecter_v4_Manual_EN.txt
  영어 사용자를 위한 영문 사용 설명서입니다.

앱의 표시 버전은 v4입니다.
한·영 공용판에는 상단 KO/EN 전환 스위치가 추가되어 있습니다. KO는 기존 한글 화면과 프리셋 한글 설명을 유지하며, EN은 영어 UI만 표시하고 프리셋 아래 한글 설명을 숨깁니다.
언어 전환은 기존 프리셋 선택과 영어 프롬프트 생성 결과를 변경하지 않습니다. 선택한 언어는 브라우저에 저장됩니다.
영어 모드에서는 한글 입력란과 번역 버튼을 숨기지만 기존 한국어 설명 데이터는 삭제하지 않습니다.
앱의 표시 명칭은 Ultra Qwen Image Edit Prompt Selector v4로 변경했습니다. 기존 북마크와 영구 저장 사용 흐름의 호환성을 위해 HTML 파일명은 Ultra_qwen_prompt_selecter_v4.html로 유지합니다. 내부 저장 키도 변경하지 않았습니다.

4. 기본 개념: image1 / image2 / image3
------------------------------------------------------------

v4에서는 Base / Reference 역할 메뉴를 제거하고, 이미지 번호 기준으로 통일했습니다.

1개 이미지 모드:
- image1 = 편집할 원본 이미지
- 예: 머리색 변경, 의상 변경, 배경 변경, 조명 변경, 보정, 제거 작업 등

2개 이미지 모드:
- image1 = 편집할 원본 이미지
- image2 = 참조 이미지
- 예: image2의 얼굴을 image1에 적용, image2의 의상을 image1에 적용, image2의 포즈를 image1에 적용 등

3개 이미지 모드:
- image1 = 편집할 원본 이미지
- image2 = 첫 번째 참조 이미지
- image3 = 두 번째 참조 이미지
- 예: image2의 의상 + image3의 포즈를 image1에 적용
- 예: image2의 메이크업 + image3의 헤어색만 image1에 적용
- 예: image2의 배경 구조 + image3의 조명 분위기를 image1에 적용

Qwen Image Edit에 이미지를 넣을 때도 이 순서를 지키는 것이 중요합니다.
앱에서 나온 프롬프트는 image1, image2, image3이라는 이름으로 이미지를 구분하기 때문입니다.


5. 화면 구성
------------------------------------------------------------

상단:
- 앱 이름과 버전이 표시됩니다.
- 현재 v4 배포본임을 확인할 수 있습니다.

1단계 이미지 수 선택:
- 1개 / 2개 / 3개 버튼 중 하나를 선택합니다.
- 선택한 이미지 수에 맞는 프리셋만 표시됩니다.
- 이미지 수를 바꾸면 프리셋 목록도 바뀝니다.

프롬프트 미리보기 영역:
- 선택한 항목이 영어 Qwen Edit 프롬프트로 조합되어 표시됩니다.
- 선택 항목이 없으면 안내 문구만 표시됩니다.
- 복사, TXT 저장, 번역 버튼을 사용할 수 있습니다.

프리셋 검색/카테고리 영역:
- 검색창에서 프리셋을 검색할 수 있습니다.
- 얼굴/헤어, 의상, 포즈, 배경, 조명, 스타일, 소품, 디테일 등 카테고리 탭을 선택할 수 있습니다.
- NSFW 버튼을 켜면 성인 항목만 따로 볼 수 있습니다.

프리셋 목록:
- 각 버튼은 하나의 편집 프리셋입니다.
- 클릭하면 선택되고, 다시 클릭하면 해제됩니다.
- 선택된 항목은 미리보기 영역에 반영됩니다.

직접 입력 영역:
- 빠르게 임시 프롬프트를 넣어 미리보기에만 반영할 수 있습니다.
- 이 영역의 내용은 파일에 저장되지 않습니다.

커스텀 항목 관리:
- 사용자가 직접 새 프리셋을 만들어 저장할 수 있는 영역입니다.
- 브라우저 localStorage 저장과 HTML 영구 저장을 지원합니다.


6. 가장 기본적인 사용 순서
------------------------------------------------------------

1) 먼저 사용할 이미지 개수를 고릅니다.

예:
- 원본 사진 1장만 고쳐야 하면 1개
- 원본 + 얼굴 참조 또는 의상 참조가 있으면 2개
- 원본 + 의상 참조 + 포즈 참조처럼 두 개의 참조가 있으면 3개

2) 카테고리를 선택합니다.

예:
- 얼굴 바꾸기: 얼굴/헤어
- 옷 바꾸기: 의상
- 자세 바꾸기: 포즈
- 배경 바꾸기: 배경
- 조명 바꾸기: 조명
- 그림체 바꾸기: 스타일
- 손/물건/소품 관련: 소품
- 보정/제거/복원: 디테일

3) 프리셋 버튼을 클릭합니다.

프리셋을 클릭하면 상단 미리보기 영역에 영어 명령문이 생성됩니다.
여러 항목을 선택하면 앱이 가능한 범위에서 충돌을 줄여 프롬프트를 정리합니다.

4) 미리보기 문장을 확인합니다.

영어 프롬프트에 image1, image2, image3이 원하는 대로 들어갔는지 확인합니다.

5) 복사 버튼을 누릅니다.

생성된 프롬프트를 Qwen Image Edit 모델의 prompt 입력칸에 붙여넣습니다.


7. 1개 이미지 모드 사용법
------------------------------------------------------------

1개 이미지 모드는 image1만 편집합니다.
참조 이미지 없이 원본 이미지 안에서 변경하거나 보정할 때 사용합니다.

사용 예시:

- 머리색을 금발로 바꾸기
- 헤어스타일을 단발로 바꾸기
- 의상을 드레스로 바꾸기
- 배경을 해변으로 바꾸기
- 조명을 따뜻하게 바꾸기
- 피부 보정하기
- 워터마크 제거하기
- 손가락이나 의상 가장자리 보정하기

프롬프트 예시 구조:

Change only the hair color in image1 to blonde. Keep face, hairstyle, pose, clothing, background, lighting, and framing in image1 unchanged.

이런 문장은 Qwen에게 “image1에서 머리색만 바꾸고 나머지는 유지하라”는 의미입니다.


8. 2개 이미지 모드 사용법
------------------------------------------------------------

2개 이미지 모드는 image1을 편집하고 image2를 참조로 사용합니다.

이미지 배치:
- image1 = 편집할 원본
- image2 = 가져올 얼굴, 의상, 포즈, 스타일, 배경, 조명 등의 참조

사용 예시:

- image2 얼굴을 image1 인물에 적용
- image2 의상을 image1 인물에게 입히기
- image2 헤어색만 image1에 적용
- image2 메이크업만 image1 얼굴에 적용
- image2 포즈만 image1에 적용
- image2 배경 분위기를 image1에 적용

좋은 사용 방법:

- image2가 무엇을 참조하는 이미지인지 명확해야 합니다.
- 얼굴 참조라면 얼굴이 잘 보이는 이미지를 쓰는 것이 좋습니다.
- 의상 참조라면 의상의 형태와 재질이 잘 보이는 이미지를 쓰는 것이 좋습니다.
- 포즈 참조라면 몸 전체나 팔·다리 방향이 잘 보이는 이미지가 좋습니다.

프롬프트 예시 구조:

Replace only the face in image1 with the face from image2. Keep hairstyle, hair color, pose, clothing, background, lighting, and framing in image1 unchanged.

이 문장은 “image2의 얼굴만 image1에 적용하고, image1의 머리·옷·포즈·배경은 유지하라”는 의미입니다.


9. 3개 이미지 모드 사용법
------------------------------------------------------------

3개 이미지 모드는 image1을 편집하고 image2와 image3을 각각 다른 참조로 사용합니다.

이미지 배치:
- image1 = 편집할 원본
- image2 = 첫 번째 참조
- image3 = 두 번째 참조

사용 예시:

- image2 의상 + image3 포즈를 image1에 적용
- image2 메이크업 + image3 헤어색을 image1에 적용
- image2 배경 구조 + image3 조명을 image1에 적용
- image2 소품 + image3 손 위치를 image1에 적용
- image2 스타일 + image3 구도를 image1에 적용

좋은 사용 방법:

- image2와 image3의 역할을 머릿속에서 정해두고 프리셋을 고르세요.
- 예를 들어 image2는 의상, image3은 포즈로 쓰겠다고 정한 뒤 의상+포즈 프리셋을 고르는 식입니다.
- 프리셋 문구에 image2와 image3이 어떻게 쓰이는지 표시되므로, 선택 전에 한글 라벨을 확인하세요.

프롬프트 예시 구조:

Apply the outfit from image2 and the pose from image3 to image1. Keep the identity in image1 unchanged.

이 문장은 “image2에서는 의상을, image3에서는 포즈를 가져오고, image1의 인물 동일성은 유지하라”는 의미입니다.


10. 프롬프트 미리보기 읽는 법
------------------------------------------------------------

미리보기에는 Qwen이 실제로 읽을 영어 문장이 표시됩니다.

중요한 표현:

- Apply A from image2 to image1
  image2의 A를 image1에 적용하라는 뜻입니다.

- Apply A from image2 and B from image3 to image1
  image2의 A와 image3의 B를 image1에 적용하라는 뜻입니다.

- Keep ... unchanged
  해당 부분은 바꾸지 말라는 뜻입니다.

- only
  특정 부분만 바꾸라는 뜻입니다.

- Remove unwanted objects
  불필요한 물체를 제거하라는 뜻입니다.

- Refine / Clean up / Repair
  보정, 정리, 복원하라는 뜻입니다.

미리보기에서 확인해야 할 점:

- image1이 편집 대상인지
- image2와 image3의 출처가 빠지지 않았는지
- 유지해야 할 부분이 Keep ... unchanged로 들어갔는지
- 원하지 않는 항목을 너무 많이 선택하지 않았는지


11. 선택 항목과 충돌방지
------------------------------------------------------------

앱은 같은 범위의 편집이 충돌할 때 일부를 정리합니다.

예:

- 머리색을 검정으로 변경 + 머리색을 금발로 변경
  둘 다 동시에 적용할 수 없으므로 나중 선택이 우선될 수 있습니다.

- 배경을 해변으로 변경 + 배경을 실내로 변경
  둘 다 동시에 적용하기 어렵기 때문에 충돌로 처리될 수 있습니다.

- 같은 얼굴 정체성 교체 항목을 여러 개 선택
  하나로 정리되거나 일부가 제외될 수 있습니다.

화면의 상태 표시에서 선택 수와 실제 적용 수를 확인할 수 있습니다.
“선택 3 · 적용 2”처럼 보인다면 1개가 충돌로 제외된 것입니다.

주의:
충돌방지는 완벽한 AI 판단이 아니라 앱 내부 규칙입니다.
중요한 편집은 미리보기 문장을 직접 확인하는 것이 가장 안전합니다.


12. 검색 기능 사용법
------------------------------------------------------------

검색창에 한국어 또는 영어 키워드를 입력하면 관련 프리셋이 필터링됩니다.

검색 예시:

- 얼굴
- 헤어
- 금발
- 의상
- 포즈
- 배경
- 조명
- 웨딩
- 란제리
- 제거
- 손
- makeup
- pose
- background
- lighting

검색 결과는 현재 이미지 수와 모드를 우선해 보여주며, 검색 중에는 다른 이미지 수의 관련 프리셋도 확인할 수 있습니다.
다른 이미지 수의 검색 결과를 선택하면 앱이 해당 이미지 수로 전환합니다.
현재 선택이 있으면 기존 선택이 해제된다는 확인 창이 먼저 표시됩니다.
의도하지 않은 선택 초기화를 막기 위해 확인 문구를 읽은 뒤 전환하세요.


13. 카테고리 설명
------------------------------------------------------------

전체:
- 현재 모드의 모든 프리셋을 보여줍니다.

얼굴/헤어:
- 얼굴, 동일성, 헤어스타일, 머리색, 눈, 입술, 메이크업, 표정 관련 작업입니다.

의상:
- 옷, 드레스, 수영복, 란제리, 신발, 소재, 패턴, 스타일링 관련 작업입니다.

포즈:
- 자세, 손 위치, 몸 각도, 시선 방향, 앉은 자세, 서 있는 자세 등을 바꾸는 작업입니다.

배경:
- 장소, 실내/실외, 풍경, 방, 거리, 침실, 무대, 배경 분위기 등을 바꾸는 작업입니다.

조명:
- 밝기, 그림자, 촛불, 네온, 달빛, 스튜디오 조명, 색온도 등을 바꾸는 작업입니다.

스타일:
- 실사풍, 일러스트풍, 회화풍, 필름룩, 색감, 렌더링 느낌을 바꾸는 작업입니다.

소품:
- 가방, 꽃, 안경, 손에 든 물체, 장신구, 제품 등 아이템 관련 작업입니다.

바디/체형:
- 체형, 피부, 비율, 일부 신체 디테일 관련 작업입니다.

표정:
- 웃음, 시선, 입 모양, 감정 표현 관련 작업입니다.

디테일:
- 손 보정, 가장자리 정리, 불필요한 물체 제거, 워터마크 제거, 해상도/노이즈/복원 보정 등입니다.

상호작용:
- 2명 또는 3명 이미지에서 인물 간 위치, 거리, 밀착, 손 위치, 시선 관계 등을 다룹니다.


14. NSFW 토글 사용법
------------------------------------------------------------

🔞 NSFW 버튼을 누르면 성인 항목만 표시됩니다.
다시 누르면 일반 모드로 돌아옵니다.

v4의 NSFW 구조:

- cat:'nsfw' 방식은 사용하지 않습니다.
- 성인 항목은 outfit, pose, detail, body, face 같은 일반 카테고리 아래 nsfw:true 속성으로 분류됩니다.
- NSFW ON 상태에서는 성인 항목을 중심으로 보여줍니다.
- NSFW OFF 상태에서는 일반 항목을 중심으로 보여줍니다.
- 모드를 바꾸어도 이미 선택한 다른 모드의 항목은 자동 삭제되지 않습니다.
- 현재 목록에 보이지 않는 선택도 상단 선택된 항목 목록과 출력에 남을 수 있습니다. 별도의 숨김 배지나 경고가 항상 나타나는 것은 아니므로 미리보기를 직접 확인하세요.
- 일반 항목과 NSFW 항목을 의도적으로 함께 쓸 수 있지만, 실제 출력에 무엇이 포함되는지 선택된 항목과 미리보기를 확인하세요.

NSFW 카테고리 예:

- 의상/노출
- 성인 포즈
- 밀착/상호작용
- 관능 표정
- 침실/무드
- 성인 소품
- 무드 조명
- 성인 스타일
- 바디/피부
- 헤어/메이크업
- NSFW 보정

주의:
Qwen 모델이나 사용하는 플랫폼의 안전 정책에 따라 일부 NSFW 프롬프트는 차단되거나 기대와 다르게 동작할 수 있습니다.
앱은 프롬프트를 만드는 도구이며, 모델의 최종 허용 여부를 보장하지 않습니다.


15. 직접 입력 기능
------------------------------------------------------------

직접 입력 영역은 빠르게 임시 지시문을 넣어볼 때 사용합니다.

특징:

- 입력한 내용은 미리보기에 반영됩니다.
- 복사와 TXT 저장에는 포함됩니다.
- 브라우저 저장에는 들어가지 않습니다.
- HTML 영구 저장에도 들어가지 않습니다.

즉, 일회성으로 프롬프트를 덧붙이고 싶을 때 사용하는 기능입니다.

예:

영문:
Add small gold earrings to image1

한글:
작은 금색 귀걸이 추가

이 입력은 현재 화면에서만 사용됩니다.
나중에도 계속 쓰려면 커스텀 항목 관리에 등록해야 합니다.


16. 커스텀 항목 관리: 임시 저장과 영구 저장의 차이
------------------------------------------------------------

앱에는 두 가지 저장 개념이 있습니다.

1) 브라우저 저장(localStorage)

커스텀 항목 관리 패널에서 항목을 추가하면 브라우저 localStorage에 저장됩니다.
브라우저를 닫았다가 다시 열어도 같은 브라우저에서는 항목이 남아 있습니다.

장점:
- 빠르고 편합니다.
- 파일을 직접 수정하지 않아도 됩니다.

단점:
- 다른 PC나 다른 브라우저로 옮기면 사라질 수 있습니다.
- 브라우저 데이터 삭제 시 사라질 수 있습니다.

2) 영구 저장(HTML에 삽입)

“영구 저장” 버튼을 사용하면 커스텀 항목이 HTML 파일의 EDITS_1 / EDITS_2 / EDITS_3 배열에 직접 들어갑니다.
이렇게 저장한 HTML은 다른 PC로 옮겨도 커스텀 항목이 기본 프리셋처럼 포함됩니다.

장점:
- 배포 파일 자체에 항목이 들어갑니다.
- 다른 환경에서도 유지됩니다.

단점:
- HTML 파일 자체가 바뀝니다.
- 실수에 대비해 원본 백업이 필요합니다.

권장 사용법:

- 테스트 중인 항목은 먼저 브라우저 저장으로 사용합니다.
- 충분히 검증한 항목만 영구 저장합니다.
- 영구 저장 전에는 ZIP 원본을 백업해둡니다.


17. 커스텀 항목 추가 방법
------------------------------------------------------------

커스텀 항목 관리 패널에서 다음 정보를 입력합니다.

이미지 개수:
- 1개 전용 / 2개 전용 / 3개 전용 중 선택합니다.
- 이 값에 따라 EDITS_1, EDITS_2, EDITS_3 중 어디에 들어갈지가 결정됩니다.

카테고리:
- 얼굴/헤어, 의상, 포즈, 배경, 조명, 스타일, 소품, 바디, 표정, 디테일 등을 선택합니다.
- 성인 항목은 “🔞 NSFW 디테일” 옵션을 사용합니다.

영문 프롬프트(en):
- Qwen이 실제로 읽는 문장입니다.
- 가능한 한 직접 명령형으로 작성하는 것이 좋습니다.

한글 설명(ko):
- 화면에 보이는 버튼 라벨입니다.
- 너무 전문적인 말보다 사용자가 바로 이해할 수 있는 쉬운 문장을 추천합니다.

예시 1개 이미지용:

카테고리: 얼굴/헤어
영문: Change only the hair color in image1 to warm brown
한글: 머리색만 따뜻한 갈색으로 변경

예시 2개 이미지용:

카테고리: 의상
영문: Apply the outfit from image2 to image1. Keep face, pose, background, and lighting in image1 unchanged
한글: image2 의상을 image1에 적용하고 얼굴·포즈·배경·조명 유지

예시 3개 이미지용:

카테고리: 포즈
영문: Apply the outfit from image2 and the pose from image3 to image1. Keep the identity in image1 unchanged
한글: image2 의상과 image3 포즈를 image1에 적용하고 인물 동일성 유지


18. 커스텀 프리셋 작성 요령
------------------------------------------------------------

좋은 영문 프롬프트는 다음 조건을 갖습니다.

- image1, image2, image3을 명확히 씁니다.
- 2개/3개 이미지용에서 reference라고만 쓰지 말고 image2 또는 image3을 직접 명시합니다.
- 무엇을 바꿀지 먼저 말합니다.
- 무엇을 유지할지 뒤에 적습니다.
- 한 문장에 너무 많은 작업을 넣지 않습니다.
- “only”를 적절히 사용합니다.

좋은 예:

Apply the hairstyle from image2 to image1. Keep face identity, hair color, pose, clothing, background, and lighting in image1 unchanged.

나쁜 예:

Make it like reference.

이 문장은 어떤 이미지의 어떤 부분을 참조해야 하는지 불명확합니다.

3개 이미지용 좋은 예:

Apply makeup style from image2 and hair color from image3 to image1. Keep the face identity in image1 unchanged.

이 문장은 image2와 image3의 역할이 명확합니다.


19. 영구 저장 사용법
------------------------------------------------------------

영구 저장은 커스텀 항목을 HTML 파일 안에 직접 넣는 기능입니다.

사용 순서:

1) 커스텀 항목 관리 패널에서 항목을 추가합니다.
2) 목록에 제대로 보이는지 확인합니다.
3) 이미지 개수와 카테고리를 바꿔가며 프리셋이 잘 표시되는지 확인합니다.
4) 프롬프트 미리보기에서 영어 문장이 자연스러운지 확인합니다.
5) 문제가 없으면 영구 저장 버튼을 누릅니다.
6) 저장된 HTML 파일을 다시 엽니다.
7) 커스텀 항목이 기본 프리셋처럼 들어갔는지 확인합니다.

주의:
직접 입력 영역의 임시 입력은 영구 저장되지 않습니다.
커스텀 항목 관리 패널에 등록한 항목만 영구 저장됩니다.
한·영 공용 기능을 보존하려면 영구 저장 시 반드시 이 ZIP의 최신 한·영 공용 HTML 파일을 선택하세요. 구버전 HTML 파일을 선택하면 저장이 차단됩니다.
원본 HTML을 백업한 뒤 저장하고, 저장·다운로드된 새 HTML을 다시 열어 확인하세요.


20. 초기화 기능
------------------------------------------------------------

초기화는 두 종류가 있습니다.

프롬프트 선택 초기화:
- 현재 선택한 프리셋만 해제합니다.
- 커스텀 저장 항목은 지우지 않습니다.

커스텀 항목 초기화:
- 브라우저 localStorage에 저장된 커스텀 항목을 지웁니다.
- 이미 영구 저장으로 HTML에 들어간 항목은 되돌리지 않습니다.

영구 저장된 항목을 제거하려면:
- 백업한 이전 HTML을 사용하거나
- HTML 소스의 EDITS 배열에서 해당 항목을 직접 삭제해야 합니다.


21. 복사 / TXT 저장 / 번역 기능
------------------------------------------------------------

복사:
- 현재 미리보기 프롬프트를 클립보드에 복사합니다.
- Qwen Image Edit의 prompt 입력칸에 붙여넣으면 됩니다.

TXT 저장:
- 현재 프롬프트를 qwen_prompt.txt 파일로 저장합니다.
- 여러 프롬프트를 기록해두고 싶을 때 유용합니다.

번역:
- 생성된 영어 프롬프트를 한국어로 확인하고 싶을 때 사용합니다.
- 번역은 이해 보조용이며, 실제 Qwen에 넣는 문장은 영어 프롬프트를 권장합니다.


22. Qwen Image Edit에서 사용하는 방법
------------------------------------------------------------

기본 흐름:

1) Qwen Image Edit 워크플로우 또는 인터페이스를 엽니다.
2) 이미지 개수에 맞게 이미지를 넣습니다.
3) 앱에서 같은 이미지 개수를 선택합니다.
4) 원하는 프리셋을 선택합니다.
5) 미리보기 영어 프롬프트를 복사합니다.
6) Qwen Image Edit의 prompt 입력칸에 붙여넣습니다.
7) 생성합니다.

중요:
Qwen 쪽 이미지 입력 순서와 앱의 image1/image2/image3 의미가 반드시 같아야 합니다.

예를 들어 앱에서 image2 의상, image3 포즈 프리셋을 골랐다면:

- Qwen 입력 1번 이미지: 편집할 원본
- Qwen 입력 2번 이미지: 의상 참조
- Qwen 입력 3번 이미지: 포즈 참조

이 순서가 맞아야 합니다.


23. 상황별 추천 사용 예시
------------------------------------------------------------

A. 얼굴만 바꾸고 싶을 때

이미지 수: 2개
image1: 원본 이미지
image2: 얼굴 참조 이미지
카테고리: 얼굴/헤어
프리셋: image2 얼굴을 image1에 적용하는 항목
확인: hairstyle, pose, clothing, background 등이 유지되는지 미리보기에서 확인

B. 옷만 바꾸고 싶을 때

이미지 수: 2개
image1: 원본 이미지
image2: 의상 참조 이미지
카테고리: 의상
프리셋: image2 의상을 image1에 적용하는 항목
확인: face, pose, background가 유지되는지 확인

C. 의상과 포즈를 동시에 가져오고 싶을 때

이미지 수: 3개
image1: 원본 이미지
image2: 의상 참조 이미지
image3: 포즈 참조 이미지
카테고리: 의상 또는 포즈
프리셋: image2 의상 + image3 포즈 적용 항목
확인: identity in image1 unchanged 같은 문장이 들어갔는지 확인

D. 배경만 바꾸고 싶을 때

이미지 수: 1개 또는 2개
1개 모드: 앱 프리셋의 배경을 직접 선택
2개 모드: image2를 배경 참조로 사용
카테고리: 배경
확인: subject, face, outfit, pose가 유지되는지 확인

E. 불필요한 물체를 제거하고 싶을 때

이미지 수: 1개 또는 3개
1개 모드: 단순 제거/보정
3개 모드: image2 깨끗한 배경 패치 + image3 조명 참조 같은 프리셋 사용
카테고리: 디테일
확인: 제거 대상 외 영역이 유지되는지 확인


24. 프롬프트 품질을 높이는 팁
------------------------------------------------------------

- 한 번에 너무 많은 항목을 선택하지 마세요.
- 얼굴, 의상, 포즈, 배경을 동시에 모두 바꾸면 모델이 헷갈릴 수 있습니다.
- 중요한 편집은 1~2개 프리셋부터 테스트하세요.
- 결과가 좋으면 조명이나 디테일 보정을 추가하세요.
- image2와 image3의 참조 목적을 명확히 정하고 사용하세요.
- 프롬프트 미리보기에서 “from image2”, “from image3”가 올바르게 들어갔는지 확인하세요.
- 유지해야 하는 부분은 Keep ... unchanged 문장이 있는지 확인하세요.


25. 한글 라벨이 애매할 때
------------------------------------------------------------

v4에서는 한글 라벨을 쉬운 표현으로 많이 정리했지만, 일부 전문 용어가 남아 있을 수 있습니다.
헷갈릴 때는 다음 순서로 확인하세요.

1) 프리셋 버튼에 마우스를 올려 설명을 봅니다.
2) 프리셋을 클릭해 영어 미리보기를 확인합니다.
3) 번역 버튼으로 의미를 확인합니다.
4) 의도와 다르면 선택을 해제합니다.

예:
“입술 산 부분에 광택 강조”는 입술 윗부분 중앙의 굴곡에 광택을 더한다는 의미입니다.
전문 용어가 불편하면 커스텀 항목을 만들어 더 쉬운 라벨로 등록할 수 있습니다.

Ultra_qwen_prompt_selecter_v4_original.zip

27. 문제 해결
------------------------------------------------------------

문제: 프리셋이 안 보입니다.
해결:
- 이미지 개수가 맞는지 확인하세요.
- NSFW 토글이 켜져 있는지 확인하세요.
- 검색창에 입력된 단어를 지워보세요.
- 다른 카테고리 탭을 눌러보세요.

문제: NSFW 항목이 안 보입니다.
해결:
- 🔞 NSFW 버튼을 켜세요.
- 이미지 개수에 맞는 NSFW 항목이 있는지 확인하세요.

문제: 커스텀 항목이 새로고침 후 사라졌습니다.
해결:
- 직접 입력 영역에만 넣은 것은 저장되지 않습니다.
- 커스텀 항목 관리 패널에서 추가했는지 확인하세요.
- 브라우저 localStorage가 삭제되었는지 확인하세요.
- 확실히 보존하려면 영구 저장을 사용하세요.

문제: 영구 저장 후 되돌리고 싶습니다.
해결:
- 백업한 이전 HTML을 사용하세요.
- 백업이 없다면 HTML 소스에서 해당 항목을 직접 제거해야 합니다.

문제: Qwen 결과가 원하는 부분 외에도 바뀝니다.
해결:
- 프리셋을 너무 많이 선택하지 마세요.
- “Keep ... unchanged” 문장이 포함된 프리셋을 사용하세요.
- 얼굴/의상/포즈/배경을 한 번에 바꾸기보다 단계별로 테스트하세요.

문제: image2와 image3이 반대로 적용된 것 같습니다.
해결:
- Qwen에 넣은 이미지 순서가 앱의 image1/image2/image3과 같은지 확인하세요.
- 3개 이미지 모드에서는 image2와 image3의 역할을 바꾸면 결과도 달라집니다.


28. 직접 HTML 수정 시 참고
------------------------------------------------------------

숙련자는 HTML 파일을 직접 열어 EDITS_1, EDITS_2, EDITS_3 배열에 항목을 추가할 수 있습니다.

기본 형식:

{cat:'face', en:'Change only the hair color in image1 to warm brown', ko:'머리색만 따뜻한 갈색으로 변경'}

성인 항목 형식:

{cat:'detail', nsfw:true, en:'...', ko:'...'}

주의:

- cat:'nsfw'는 사용하지 마세요.
- NSFW 항목은 일반 카테고리 안에 nsfw:true를 붙입니다.
- en은 Qwen이 읽는 실제 영어 문장입니다.
- ko는 화면에 보이는 한글 라벨입니다.
- 작은따옴표, 역슬래시, 줄바꿈, </script> 같은 문자는 주의해야 합니다.
- 직접 수정 후에는 브라우저에서 열어 오류가 없는지 확인하세요.


29. v4 공개본에서 달라진 점
------------------------------------------------------------

v4는 사용자가 한글 작업 설명만 보고도 실제 영어 편집 명령을 더 정확히 예상할 수 있도록 프롬프트 체계를 정리한 공개 버전입니다.

주요 변화:

- image1은 항상 최종 편집 대상이라는 원칙을 강화했습니다.
- 2개 이미지 모드는 image2의 어떤 요소를 image1의 어디에 적용하는지 직접 표현합니다.
- 3개 이미지 모드는 image2의 요소와 image3의 요소가 각각 image1에 적용되도록 역할을 분리합니다.
- 얼굴, 헤어, 의상, 포즈, 배경, 조명, 스타일, 소품, 표정, 디테일마다 적합한 동사를 사용합니다.
- Apply 또는 Change 하나로 모든 작업을 통일하지 않습니다.
- 부분 변경에는 only를 사용하고, 유지해야 할 부분은 필요한 범위에서 Keep 또는 Preserve로 표시합니다.
- 변경 대상과 유지 조건이 충돌하지 않도록 실제 변경 속성을 기준으로 유지 문장을 조정합니다.
- 배경 장소와 날씨, 전체 의상과 세부 장식, 몸 방향과 시선처럼 함께 쓸 수 있는 작업은 가능한 한 함께 유지합니다.
- 같은 머리색 두 개, 같은 배경 장소 두 개처럼 실제로 배타적인 선택은 나중 선택이 우선될 수 있습니다.
- 일반 항목과 NSFW 항목 모두 image 역할과 작업 대상을 직접 설명하는 문장으로 정리했습니다.
- NSFW 다인 작업은 image1의 성인 인물, image2의 참조 인물 또는 요소, image3의 포즈·구도·추가 인물 역할을 구분합니다.
- 커스텀 프롬프트 입력 시 image1 편집 대상과 현재 이미지 개수 범위의 참조 번호를 사용자가 직접 확인해야 합니다. 현재 등록 코드는 영문 문장 내부의 모든 image 번호 오류를 자동 차단하지 않습니다.
- SFW/NSFW 모드 전환 후 현재 목록에서 보이지 않는 선택도 출력에 남을 수 있으므로 상단 선택 항목과 실제 영어 미리보기를 직접 확인해야 합니다.
- 다른 이미지 수의 검색 결과를 선택할 때 기존 선택 삭제 여부를 확인합니다.
- 프리셋 한글 문구는 직역보다 실제 작업 형태를 알리는 설명을 우선합니다.

프리셋 수:

- 1개 이미지 전용: 2,172개 (일반 1,502개 / NSFW 670개)
- 2개 이미지 전용: 1,652개 (일반 1,056개 / NSFW 596개)
- 3개 이미지 전용: 1,103개 (일반 504개 / NSFW 599개)
- 전체 기본 프리셋: 4,927개

커스텀 항목을 추가하면 표시되는 항목 수는 달라질 수 있습니다.


30. 마지막 권장 사용법
------------------------------------------------------------

초보자에게 가장 안전한 사용법은 다음과 같습니다.

1) 이미지 수를 먼저 정확히 고릅니다.
2) 하나의 카테고리에서 한두 개 프리셋만 선택합니다.
3) 미리보기 영어 문장을 확인합니다.
4) image1/image2/image3 출처가 맞는지 봅니다.
5) 복사해서 Qwen Image Edit에 넣습니다.
6) 결과가 안정되면 추가 프리셋을 하나씩 더합니다.

가장 중요한 원칙은 이것입니다.

image1은 편집할 원본입니다.
image2와 image3은 필요한 부분을 가져오는 참조 이미지입니다.
프롬프트 미리보기에서 이 순서가 올바른지만 확인하면 앱을 안정적으로 사용할 수 있습니다.


31. v4를 처음 사용하는 사람을 위한 5분 시작 가이드
------------------------------------------------------------

처음에는 모든 기능을 한 번에 이해할 필요가 없습니다.
아래 순서만 따르면 가장 기본적인 프롬프트를 만들 수 있습니다.

1) 압축을 풉니다.
2) Ultra_qwen_prompt_selecter_v4.html을 크롬 또는 엣지에서 엽니다.
3) Qwen에 넣을 이미지 수와 같은 1개 / 2개 / 3개 모드를 선택합니다.
4) 검색창에서 얼굴, 의상, 포즈, 배경처럼 원하는 작업을 검색합니다.
5) 한글 작업 설명을 읽고 프리셋을 클릭합니다.
6) 상단 선택된 항목과 영어 미리보기를 확인합니다.
7) image1, image2, image3의 방향이 실제 이미지 배치와 맞는지 확인합니다.
8) 복사 버튼을 누릅니다.
9) Qwen Image Edit 프롬프트 입력칸에 붙여넣습니다.
10) 처음에는 한두 개의 작업만 선택해 결과를 확인합니다.

가장 안전한 첫 테스트:

- image1 한 장만 사용할 때: 머리색만 변경
- image1과 image2를 사용할 때: image2 의상만 image1에 적용
- image1, image2, image3을 사용할 때: image2 의상 + image3 포즈를 image1에 적용

처음부터 얼굴, 의상, 포즈, 배경, 조명, 스타일을 모두 바꾸면 모델이 우선순위를 놓칠 수 있습니다.
작업을 두 단계로 나누는 것이 결과가 더 좋은 경우도 많습니다.


32. v4 프롬프트가 만들어지는 방식
------------------------------------------------------------

v4는 선택한 한글 버튼을 단순히 영어 단어로 연결하지 않습니다.
각 프리셋에는 Qwen이 읽을 실제 영어 작업 명령이 들어 있습니다.

프롬프트 생성 과정은 대체로 다음과 같습니다.

1) 사용자가 선택한 이미지 수를 확인합니다.
2) 선택한 프리셋의 image1 / image2 / image3 역할을 확인합니다.
3) 같은 속성을 서로 다르게 바꾸는 충돌 항목을 정리합니다.
4) 함께 사용할 수 있는 부분 작업은 가능한 한 유지합니다.
5) 변경 대상과 직접 충돌하는 유지 조건을 제외합니다.
6) 필요한 경우 원본 유지 문장을 추가합니다.
7) 문장을 Qwen이 읽기 쉬운 직접 명령형으로 정리합니다.
8) 같은 결과를 미리보기, 복사, TXT 저장에 사용합니다.

예를 들어 다음 두 선택은 함께 사용할 수 있습니다.

- 배경을 겨울 숲으로 변경
- 눈이 내리는 효과 추가

장소와 날씨는 다른 속성이므로 둘 다 적용될 수 있습니다.

다음 두 선택은 충돌할 가능성이 큽니다.

- 머리색을 검정으로 변경
- 머리색을 금발로 변경

같은 머리색을 두 값으로 동시에 바꿀 수 없으므로 나중 선택이 우선될 수 있습니다.


33. 한글 작업 설명을 읽는 법
------------------------------------------------------------

v4의 한글 문구는 영어 문장을 그대로 직역한 제목이 아닙니다.
사용자가 실제 작업 형태를 알 수 있도록 만든 설명입니다.

예:

image2 머리 색상만 image1에 적용

이 문구에서 알 수 있는 것:

- 편집 대상은 image1입니다.
- 참조 이미지는 image2입니다.
- 가져오는 것은 머리 색상입니다.
- 헤어스타일 전체를 교체하는 작업은 아닙니다.

예:

image2 얼굴과 image3 헤어스타일을 image1에 적용하고 포즈·의상·배경 유지

이 문구에서 알 수 있는 것:

- image2는 얼굴 참조입니다.
- image3은 헤어스타일 참조입니다.
- 최종 결과는 image1에 만들어집니다.
- 포즈, 의상, 배경은 가능한 한 image1 상태를 유지합니다.

한글 문구가 길어 보이더라도 다음 정보가 포함되어 있으면 유용합니다.

- 무엇을 바꾸는지
- 어디서 가져오는지
- 어디에 적용하는지
- 무엇을 유지하는지


34. image1을 준비하는 방법
------------------------------------------------------------

image1은 최종 편집 대상입니다.
Qwen이 결과를 안정적으로 만들려면 image1의 품질도 중요합니다.

권장 사항:

- 편집하려는 인물이나 물체가 지나치게 작지 않은 이미지를 사용합니다.
- 얼굴 편집은 얼굴이 어느 정도 선명한 image1이 좋습니다.
- 의상 편집은 몸과 의상 영역이 충분히 보이는 image1이 좋습니다.
- 포즈 편집은 팔과 다리가 잘리지 않은 image1이 유리합니다.
- 배경 편집은 인물과 배경 경계가 어느 정도 구분되는 image1이 좋습니다.
- 손, 액세서리, 작은 소품 편집은 해당 부위의 해상도가 너무 낮지 않아야 합니다.

image1에서 이미 심하게 가려진 부분은 참조 이미지가 좋아도 정확히 복원되지 않을 수 있습니다.
이 경우에는 먼저 디테일 복원이나 가림 제거를 수행한 뒤 다른 편집을 시도하는 것이 좋습니다.


35. image2와 image3 참조 이미지를 준비하는 방법
------------------------------------------------------------

참조 이미지는 가져올 요소가 분명하게 보여야 합니다.

얼굴 참조:

- 얼굴이 너무 작지 않은 이미지를 사용합니다.
- 얼굴이 손이나 머리카락에 심하게 가려지지 않은 것이 좋습니다.
- 측면 얼굴을 정면 얼굴에 적용하면 결과가 불안정할 수 있습니다.

의상 참조:

- 의상 전체 디자인을 가져올 때는 전신 또는 상하의가 잘 보이는 이미지를 사용합니다.
- 원단이나 패턴만 가져올 때는 해당 질감이 선명한 이미지가 좋습니다.
- 의상 참조 속 인물의 포즈가 너무 복잡하면 의상과 포즈가 함께 따라올 수 있습니다.

포즈 참조:

- 팔, 다리, 몸 방향이 잘 보이는 이미지를 사용합니다.
- 카메라 각도가 image1과 지나치게 다르면 포즈와 구도가 함께 변할 수 있습니다.
- 손가락처럼 작은 자세는 고해상도 참조가 유리합니다.

배경 참조:

- 장소 구조를 가져올지, 색 분위기만 가져올지 먼저 결정합니다.
- 인물이 없는 깨끗한 배경 참조는 배경 교체에 유리할 수 있습니다.
- 조명까지 함께 가져오고 싶지 않다면 배경 구조 전용 프리셋을 선택합니다.

조명 참조:

- 광원의 방향과 색이 분명한 이미지가 좋습니다.
- 단순히 밝기만 맞추고 싶은 경우에는 전체 장면 스타일 참조보다 조명 전용 프리셋을 사용합니다.


36. 여러 프리셋을 함께 선택하는 방법
------------------------------------------------------------

v4는 복수 선택을 지원하지만, 모든 조합이 항상 좋은 결과를 만드는 것은 아닙니다.

좋은 조합 예:

- 의상 전체 교체 + 의상 패턴 적용
- 배경 장소 변경 + 비 또는 눈 효과
- 전체 포즈 적용 + 시선 방향 변경
- 얼굴 교체 + 헤어스타일 적용
- 스타일 변경 + 세부 선명도 보정
- 조명 분위기 변경 + 그림자 정리

주의가 필요한 조합:

- 얼굴 교체 + 얼굴 형태 유지
- 전체 의상 교체 + 기존 의상 전체 유지
- 전신 포즈 교체 + 기존 포즈 유지
- 배경 장소 두 개 동시 선택
- 머리색 두 개 동시 선택
- 서로 다른 카메라 구도 두 개 동시 선택

앱의 충돌 정리가 모든 의미를 사람처럼 판단하는 것은 아닙니다.
선택이 많을수록 미리보기 문장을 직접 읽는 것이 중요합니다.

권장 선택 수:

- 단순 편집: 1~2개
- 두 참조 결합: 1개의 복합 프리셋 또는 2~3개의 보조 프리셋
- 복잡한 작업: 3~5개 이하부터 테스트

결과가 안정된 뒤 디테일 작업을 추가하는 것이 좋습니다.


37. 충돌 상태 표시를 읽는 법
------------------------------------------------------------

미리보기 위에는 선택 수와 실제 적용 수가 표시됩니다.

예:

선택 3 · 적용 3 · 충돌 없음

세 항목이 모두 출력에 들어갑니다.

예:

선택 3 · 적용 2

세 항목을 눌렀지만 하나가 같은 속성과 충돌하여 제외됐을 수 있습니다.

충돌로 제외될 수 있는 대표 사례:

- 서로 다른 머리색
- 서로 다른 전체 헤어스타일
- 서로 다른 배경 장소
- 서로 다른 전체 의상
- 서로 다른 기본 포즈

함께 유지될 수 있는 대표 사례:

- 배경 장소 + 날씨
- 배경 장소 + 시간대
- 의상 전체 + 작은 의상 디테일
- 몸 방향 + 시선
- 포즈 + 표정

선택 순서에 따라 나중 선택이 우선되는 경우가 있으므로, 중요한 항목은 마지막 미리보기에서 확인하세요.


38. SFW와 NSFW 선택을 함께 사용할 때
------------------------------------------------------------

v4는 일반 항목과 NSFW 항목을 별도 목록으로 보여주지만, 이미 선택한 항목은 모드를 바꾸어도 자동으로 삭제하지 않습니다.

예:

1) 일반 모드에서 얼굴 유지 프리셋 선택
2) NSFW 모드로 전환
3) NSFW 의상 또는 포즈 프리셋 선택

이 경우 일반 얼굴 유지와 NSFW 작업이 함께 출력될 수 있습니다.

현재 목록에서 보이지 않는 선택은 삭제된 것이 아니라 필터 때문에 카드 목록에서만 보이지 않는 상태일 수 있습니다.
현재 앱에서는 숨김 선택에 대한 별도 배지나 경고가 항상 나오지 않습니다. 선택 목록과 실제 출력 프롬프트를 확인해야 합니다.

확인 방법:

- 상단 선택된 항목을 봅니다.
- 현재 SFW/NSFW 필터에서 보이지 않는 선택이 남아 있는지 살펴봅니다.
- 실제 영어 미리보기에 해당 항목이 포함되는지 확인합니다.
- 필요 없는 항목은 선택 pill에서 제거하거나 해당 모드로 돌아가 해제합니다.

성인 항목은 성인 대상이라는 전제가 명확한 프롬프트로 구성되어 있습니다.
미성년자 또는 연령이 불분명한 대상을 성인 편집 프롬프트와 함께 사용하지 마세요.
사용하는 서비스와 모델의 정책도 반드시 따라야 합니다.

프롬프트는 가능한 한 image1의 어떤 대상에 작업하는지를 명시합니다.

사용 팁:

- 의상과 노출을 크게 바꿀 때는 포즈와 배경 변경을 한꺼번에 너무 많이 선택하지 마세요.

40. NSFW 2개 이미지 모드 사용법

2개 이미지 NSFW 모드의 기본 관계:

42. 직접 입력과 커스텀 항목의 차이

직접 입력:

커스텀 항목 관리:

임시 문장을 여러 번 사용할 계획이라면 커스텀 항목으로 등록하는 것이 좋습니다.


43. 커스텀 프롬프트 이미지 번호 점검
------------------------------------------------------------

v4에서는 커스텀 항목을 등록할 때 이미지 개수 선택값, 카테고리, 영문 입력 여부를 확인합니다.
다만 현재 버전은 영문 프롬프트 문장 안에 적힌 image 번호를 모두 검사하거나 범위를 벗어난 image4를 자동으로 차단하지는 않습니다.
따라서 아래 규칙에 따라 사용자가 직접 확인해야 합니다.

1개 이미지 전용:

- image1만 실제 편집 대상으로 사용합니다.
- image2, image3, image4 등을 참조하는 문장을 입력하지 마세요.

2개 이미지 전용:

- image1은 편집 대상, image2는 참조 이미지입니다.
- image3 이상의 번호를 사용하지 마세요.

3개 이미지 전용:

- image1은 편집 대상, image2와 image3은 참조 이미지입니다.
- image4 이상의 번호는 지원하지 않습니다.

좋지 않은 예:

Apply the face from image2

어디에 적용할지 편집 대상이 빠져 있습니다.

좋은 예:

Apply the face from image2 to the face in image1

또한 1개 이미지용에 image4를 쓰는 등 잘못된 번호를 입력해도 등록 자체는 진행될 수 있으므로,
등록 전과 실제 Qwen 입력 전에 반드시 image1/image2/image3 참조를 확인하세요.
이는 현재 ZIP의 실제 동작을 기준으로 한 안내이며, 자동 차단 기능이 있다고 가정해서는 안 됩니다.


44. 좋은 커스텀 영문을 만드는 규칙
------------------------------------------------------------

규칙 1. 실제 편집 대상을 직접 씁니다.

좋음:

Change the hair color in image1 to warm brown

모호함:

Change the subject

규칙 2. 참조 출처를 요소 가까이에 씁니다.

좋음:

Apply the outfit from image2 to the person in image1

모호함:

Apply the outfit while preserving image1 from image2

규칙 3. 3개 이미지는 두 역할을 분리합니다.

좋음:

Apply the outfit from image2 to image1. Set the pose in image1 to match image3.

모호함:

Combine image2 and image3

규칙 4. 전체 교체와 부분 변경을 구분합니다.

- 전체 교체: Replace, Change the entire, Dress the person in
- 부분 적용: Apply only, Change only, Match only
- 보정: Refine, Repair, Clean up, Adjust
- 제거: Remove
- 추가: Add, Place

규칙 5. 변경하는 항목을 다시 유지하라고 하지 않습니다.

나쁜 예:

Replace the clothing in image1. Keep the clothing unchanged.

좋은 예:

Replace the clothing in image1. Keep the face, pose, background, and lighting unchanged.


45. 한글 커스텀 설명 작성 요령
------------------------------------------------------------

한글 설명은 영어를 단어 단위로 직역할 필요가 없습니다.
사용자가 선택 전에 실제 작업을 알 수 있어야 합니다.

image2의 의상 무늬만 image1 의상에 적용

부족한 설명:

무늬 적용

image2 얼굴과 image3 헤어스타일을 image1에 적용하고 포즈·의상 유지

얼굴과 머리 변경

46. 영구 저장을 안전하게 사용하는 방법
------------------------------------------------------------

영구 저장은 현재 HTML에 커스텀 항목을 포함한 새 HTML을 저장하는 기능입니다.

안전한 순서:

1) 원본 ZIP을 별도 폴더에 보관합니다.
2) 커스텀 항목을 먼저 브라우저 저장으로 테스트합니다.
3) 이미지 수와 카테고리를 바꾸어 항목이 올바르게 나타나는지 확인합니다.
4) 실제 생성 프롬프트를 확인합니다.
5) Qwen에서 한두 번 테스트합니다.
6) 문제가 없을 때 영구 저장합니다.
7) 저장된 Ultra_qwen_prompt_selecter_v4.html을 다시 엽니다.
8) 커스텀 항목이 기본 항목처럼 표시되는지 확인합니다.

영구 저장 버튼이 같은 파일명 덮어쓰기를 지원하는 환경도 있지만, 브라우저 권한이나 실행 방식에 따라 새 파일 다운로드로 처리될 수 있습니다.
저장 후 실제 파일 위치와 이름을 확인하세요.


47. 번역 기능을 사용할 때 주의할 점
------------------------------------------------------------

번역은 영어 프롬프트의 뜻을 확인하기 위한 보조 기능입니다.
Qwen에 입력할 최종 문장은 원래 영어 프롬프트를 권장합니다.

자동 번역은 다음을 부정확하게 옮길 수 있습니다.

- identity
- framing
- exposure state
- subject
- preserve
- transfer
- match
- reference

번역 결과가 어색하더라도 원래 영어 프롬프트가 잘못됐다는 뜻은 아닙니다.
한글 프리셋 설명과 영어 원문을 함께 비교하세요.


48. Qwen 결과가 지시를 따르지 않을 때 조정 순서
------------------------------------------------------------

1) 이미지 순서를 확인합니다.
2) image1, image2, image3이 프롬프트와 일치하는지 확인합니다.
3) 선택한 프리셋 수를 줄입니다.
4) 가장 중요한 작업 하나만 남겨 테스트합니다.
5) 서로 충돌하는 작업이 없는지 확인합니다.
6) 참조 이미지에서 가져올 요소가 잘 보이는지 확인합니다.
7) 포즈와 카메라 각도가 지나치게 다른지 확인합니다.
8) 얼굴과 의상을 동시에 바꾸는 작업을 분리합니다.
9) 전체 변경 대신 부분 변경 프리셋을 사용해 봅니다.
10) 여러 시드로 결과를 비교합니다.

모델이 유지 조건 때문에 변화가 약할 때:

- 더 직접적인 교체 프리셋을 사용합니다.
- 부분 변경 프리셋과 전체 교체 프리셋을 혼동하지 않았는지 확인합니다.
- 불필요한 Preserve 또는 Keep 문장이 포함된 커스텀 문장을 제거합니다.

모델이 너무 많이 바꿀 때:

- only가 들어간 프리셋을 사용합니다.
- 얼굴, 포즈, 배경, 조명 유지 문장이 있는 프리셋을 선택합니다.
- 작업을 단계별로 나눕니다.

50. 모바일과 작은 화면에서 사용하는 방법
------------------------------------------------------------

v4는 작은 화면에서도 사용할 수 있도록 구성되어 있지만, 프리셋이 많기 때문에 데스크톱이 더 편리합니다.

모바일 사용 팁:

- 검색창을 적극적으로 사용합니다.
- 카테고리를 먼저 좁힙니다.
- 선택된 항목은 상단 pill에서 확인합니다.
- 긴 영어 미리보기는 가로 스크롤보다 줄바꿈 상태로 확인합니다.
- 복사 후 Qwen 앱이나 웹페이지로 이동합니다.

브라우저가 파일 다운로드나 클립보드 권한을 요청할 수 있습니다.
권한이 거부되면 복사 또는 영구 저장이 제한될 수 있습니다.


51. 브라우저 저장과 개인정보
------------------------------------------------------------

커스텀 항목은 브라우저 localStorage에 저장될 수 있습니다.
이 데이터는 일반적으로 현재 브라우저 프로필 안에 보관됩니다.

주의:

- 공용 PC에서는 민감한 커스텀 문구를 저장하지 않는 것이 좋습니다.
- 브라우저 데이터 삭제 시 커스텀 항목이 사라질 수 있습니다.
- 시크릿 모드에서는 창을 닫을 때 저장 데이터가 사라질 수 있습니다.
- 다른 브라우저와 자동으로 동기화되지 않을 수 있습니다.
- HTML 영구 저장본에는 선택한 커스텀 항목의 영문과 한글이 파일 안에 들어갑니다.

배포하거나 공유하기 전에 개인용 커스텀 항목이 포함되어 있지 않은지 확인하세요.


52. 파일을 공유할 때 확인할 점
------------------------------------------------------------

공개 배포 또는 다른 사람에게 전달하기 전:

- 파일명이 Ultra_qwen_prompt_selecter_v4.html인지 확인합니다.
- 메뉴얼이 Ultra_qwen_prompt_selecter_v4_메뉴얼.txt인지 확인합니다.
- 개인 커스텀 항목이 영구 저장되어 있지 않은지 확인합니다.
- 브라우저 저장 항목은 ZIP에 자동 포함되지 않지만, 영구 저장 항목은 HTML에 포함됩니다.
- ZIP을 다시 풀어 HTML과 한·영 사용 설명서 총 세 파일이 정상적으로 열리는지 확인합니다.
- HTML을 브라우저에서 열어 프리셋과 미리보기가 나타나는지 확인합니다.


53. 자주 묻는 질문
------------------------------------------------------------

Q. image2와 image3은 항상 정해진 카테고리 역할인가요?

A. 아닙니다. 선택한 프리셋에 따라 역할이 달라집니다. 한글 설명과 영어 미리보기에서 각 이미지가 무엇을 제공하는지 확인하세요.

Q. 프리셋을 많이 선택하면 더 정확해지나요?

A. 항상 그렇지 않습니다. 작업이 많으면 모델이 우선순위를 놓칠 수 있습니다. 핵심 작업부터 적게 선택하는 것이 좋습니다.

Q. 한글 설명만 복사해도 되나요?

A. 실제 Qwen 입력에는 영어 미리보기를 권장합니다. 한글은 작업을 이해하고 선택하기 위한 설명입니다.

Q. NSFW 모드를 끄면 이전 NSFW 선택이 삭제되나요?

A. 자동 삭제되지 않습니다. 현재 필터에서 카드가 보이지 않아도 선택 목록과 미리보기에 남을 수 있으므로 직접 확인하세요.

Q. 같은 항목을 두 번 클릭하면 어떻게 되나요?

A. 일반적으로 다시 클릭하면 선택이 해제됩니다.

Q. 검색 결과에서 다른 이미지 수 항목을 누르면 어떻게 되나요?

A. 해당 이미지 수로 전환됩니다. 기존 선택이 있으면 해제 확인 창이 나타납니다.

Q. 커스텀 문장에 image4를 쓸 수 있나요?

A. 현재 앱은 최대 3개 이미지 모드이므로 image4를 사용하면 안 됩니다. 다만 현재 버전은 영문 문장 내부의 image4를 등록 단계에서 자동 차단하지 않으므로 직접 점검해야 합니다.

Q. 영구 저장 후 원래 상태로 되돌릴 수 있나요?

A. 앱 안에서 자동으로 이전 파일을 복원하지는 않습니다. 원본 ZIP 또는 백업 HTML을 사용하세요.

Q. 모델이 프롬프트를 일부 무시하는 것은 앱 오류인가요?

A. 프롬프트가 정상이어도 모델, 워크플로우, 해상도, 시드, 참조 이미지 품질에 따라 일부 지시가 약하게 반영될 수 있습니다.

55. 마지막 사용 원칙
------------------------------------------------------------

Ultra Qwen Image Edit Prompt Selector v4에서 가장 중요한 원칙은 다음과 같습니다.

첫째, image1은 최종 편집 대상입니다.

둘째, image2와 image3은 선택한 프리셋이 지정하는 요소를 제공하는 참조 이미지입니다.

셋째, 한글 문구는 실제 작업 형태를 이해하기 위한 설명이고 영어 미리보기는 Qwen이 읽는 최종 명령입니다.

넷째, 프리셋을 많이 선택하는 것보다 정확한 프리셋을 적게 선택하는 것이 더 좋은 결과를 만들 수 있습니다.

다섯째, 복잡한 편집은 한 번에 끝내려 하지 말고 얼굴, 의상, 포즈, 배경, 디테일 순으로 나누어 수행하는 것도 좋은 방법입니다.

여섯째, 실제 결과는 모델과 참조 이미지의 품질에도 영향을 받으므로 미리보기 프롬프트가 정확하더라도 여러 시드를 시험할 수 있습니다.

일반 항목과 NSFW 항목 모두 같은 image 역할 원칙을 따릅니다.
항상 마지막 영어 미리보기에서 image1, image2, image3의 방향을 확인한 뒤 사용하세요.
